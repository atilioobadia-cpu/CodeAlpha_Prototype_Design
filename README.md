# Task 4: Mini Project - Prototype Design (Online Learning Platform)

**Domain:** UI/UX Design
**Internship:** CodeAlpha - Month 1

## Overview
Clickable prototype of an Online Learning Platform ("LearnHub") with 5 screens (Home, Course Detail, Lesson Player with quiz, Profile, Search) plus bottom navigation and interactions.

## Deliverables
- prototype.html - clickable interactive prototype (open in browser)
- screen1_home.png .. screen5_search.png - exported screens
- design_explanation.html / design_explanation.pdf - 2-3 page design explanation
- profile.jpg - avatar (Atilio Obadia)
- README.md

## Tech
HTML, CSS, JavaScript (no build step). Nunito typography. Lucide icons. Real images.

## Interactions
- Tap course card -> Course Detail
- Continue -> Lesson Player
- Quiz options highlight correct/wrong
- Bottom nav switches screens
- Toast feedback

Upload to Google Drive as CodeAlpha_Prototype_Design, share clickable link + video on LinkedIn, submit via form.
