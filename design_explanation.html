Mini Project — Prototype Design: LearnHub

CodeAlpha Internship — Month 1 · Task 4 (UI/UX Design) · Online Learning Platform

1. Concept

LearnHub is a mobile-first online learning platform. The clickable prototype demonstrates the core learning loop: discover courses → open course → watch lesson → take quiz → track progress → view profile.

2. Screens

  • Home: search, category chips, "Continue Learning" card with progress, recommended courses.
  • Course Detail: course info, progress, lesson list with done/in-progress states.
  • Lesson Player: video placeholder, description, quick quiz with answer feedback.
  • Profile: avatar, stats (courses/lessons/hours), achievements.

3. Design Decisions

  • Color: Indigo (#4F46E5) as primary — conveys trust and focus; soft indigo surfaces for chips.
  • Typography: Inter for clean, modern readability across sizes.
  • Navigation: Bottom nav with 4 tabs (Home, Courses, Lesson, Profile) for thumb reach.
  • Feedback: Progress bars, done checkmarks, quiz correct/wrong coloring.
  • Accessibility: 44px+ tap targets, clear contrast, focusable controls.

4. Interactions

  • Tapping a course card opens Course Detail.
  • "Continue" opens the Lesson Player at the next lesson.
  • Quiz options highlight green (correct) / red (wrong) on tap.
  • Bottom nav switches between Home, Courses, Lesson, Profile.
  • "Back to Home" returns to Home from Lesson.

5. Tools & Tech

Designed as an interactive HTML/CSS/JS prototype (mirroring a Figma prototype). Screens exported as PNG for submission. Can be opened in any browser; no build step required.

6. Submission

Upload the prototype folder to Google Drive as CodeAlpha_Prototype_Design, share the clickable link, post a video explanation on LinkedIn, and submit via the CodeAlpha form.
